
# BookSpace

BookSpace — информационный сайт для любителей книг, созданный в рамках учебного проекта.

## Описание проекта

Сайт предназначен для поиска интересных книг, просмотра информации о произведениях и создания личной библиотеки.

Аналог проекта — [Goodreads](https://www.goodreads.com/).

## Страницы сайта

- Главная — новинки, рекомендации и книга дня.
- Каталог — список книг с поиском и фильтрацией по жанрам.
- Страница книги — описание произведения, автор, жанр и рейтинг.
- Моя библиотека — сохранённые книги с разделением по статусу чтения.
- FAQ — ответы на часто задаваемые вопросы.

## Технологии

- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript
- localStorage для хранения личной библиотеки

- Подключён Bootstrap 5.3.3.

### Этап 4. Разработка каталога книг

- Создана страница `catalog.html`.
- Добавлены карточки книг с обложками, названиями и авторами.

- Добавлено поле поиска книг по названию и автору.
