Технологии разработки

Для создания BookSpace использованы технологии, которые отвечают за структуру, оформление и интерактивность сайта.

HTML5

HTML5 используется для создания структуры страниц BookSpace. С его помощью организованы навигационное меню, каталог книг, карточки произведений и формы. Семантические элементы делают разметку понятной и логичной.

CSS3

CSS3 отвечает за визуальное оформление сайта. С его помощью создана единая коричнево-бежевая цветовая гамма, настроены шрифты, отступы, изображения и эффекты при наведении. Также стили адаптируют оформление под разные экраны.

Bootstrap 5.3.3

Bootstrap 5.3.3 используется для создания адаптивного интерфейса. Сетка Bootstrap помогает правильно располагать карточки книг и другие элементы на компьютерах и смартфонах. Также применяются готовые компоненты: навигационная панель, кнопки, формы и Accordion.

JavaScript

JavaScript обеспечивает интерактивность BookSpace. Он позволяет искать книги по названию и автору, фильтровать каталог по жанрам, добавлять произведения в личную библиотеку, изменять их статусы и удалять из коллекции.

localStorage

localStorage используется для хранения данных личной библиотеки непосредственно в браузере. Благодаря этому выбранные книги и их статусы сохраняются после обновления или закрытия страницы. Для работы этой функции не требуется серверная база данных.
